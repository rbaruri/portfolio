# Rajasree Baruri — Portfolio

Personal portfolio site for **Rajasree Baruri**, Software Engineer based in Bengaluru.

Built with React and Vite. Content lives in one file so updates stay simple.

## Stack

- React 19
- Vite 8
- Plain CSS (no UI kit)

## Run locally

```bash
npm install
npm run dev
```

Open the URL Vite prints (usually `http://127.0.0.1:5173`).

## Scripts

| Command | What it does |
| --- | --- |
| `npm run dev` | Start the local dev server |
| `npm run build` | Production build into `dist/` |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |

## Project layout

```
src/
  App.jsx       # Page sections and layout
  App.css       # Styles
  content.js    # Profile, experience, systems, projects, skills
  index.css     # Global tokens and base styles
  main.jsx      # React entry
index.html
```
